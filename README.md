# Titanic Dataset - Exploratory Data Analysis

## Internship Task 2

This project focuses on Exploratory Data Analysis (EDA) of the Titanic dataset.

## Objective

The objective of this task is to understand the dataset using descriptive statistics and visualizations.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

Titanic Dataset.

## EDA Steps

1. Imported the required Python libraries.
2. Loaded the Titanic dataset.
3. Explored the dataset structure and data types.
4. Generated summary statistics.
5. Checked missing values.
6. Created histograms for numerical features.
7. Created boxplots to identify potential outliers.
8. Created survival count visualizations.
9. Analyzed survival based on gender.
10. Analyzed survival based on passenger class.
11. Created a pairplot to understand feature relationships.
12. Created a correlation matrix to identify relationships between numerical features.
13. Identified patterns, trends and possible anomalies.
14. Recorded basic observations from the visualizations.

## Key Findings

- Passenger ages are concentrated mainly in younger and middle-age groups.
- Fare distribution is right-skewed with some high-value observations.
- Survival rates differ between male and female passengers.
- Passenger class shows a noticeable relationship with survival.
- The correlation matrix helps identify relationships between numerical features.
- EDA helps understand the dataset before applying machine learning algorithms.
